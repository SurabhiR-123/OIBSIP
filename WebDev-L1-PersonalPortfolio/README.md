# Task 2 – Personal Portfolio Website

## 📌 Project Overview

This project is a personal portfolio website developed as part of my **Oasis Infobyte Web Development Internship**.

The portfolio showcases my profile, technical skills, projects, educational background, and contact information through a clean, modern, and responsive design.

## ✨ Features

- **Home Section:** Introduction and personal profile.
- **About Me:** Brief information about my background.
- **Skills Section:** Displays technical skills and technologies.
- **Projects Section:** Highlights my projects and development work.
- **Education Section:** Showcases academic qualifications.
- **Contact Section:** Provides ways to connect with me.
- **Responsive Design:** Adapts to different screen sizes.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Tailwind CSS

4. Explore the portfolio website.
