# GlowNest – Skincare Landing Page

A clean and modern skincare landing page built as part of the **Oasis Infobyte** internship.

---

## About the Project
GlowNest is a responsive skincare landing page that presents products through a simple, elegant, and user-friendly design. It focuses on everyday hydration and natural skincare rituals.

---

## Features
- Responsive navigation bar with mobile menu
- Hero / Home section with product visuals
- About section
- Features section highlighting product benefits
- Customer reviews section
- Contact section with form
- Fully responsive layout for mobile, tablet, and desktop

---

## Technologies Used
- HTML5
- CSS3
- Remix Icon

## How to Run
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `glownest.html` in your browser  
   **or**  
   Use the **Live Server** extension.
