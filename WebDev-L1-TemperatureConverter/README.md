# Task 3 – Temperature Converter

## 📌 Project Overview

This project is a Temperature Converter Web Application developed as part of my **Oasis Infobyte Web Development Internship**.

The application allows users to convert temperatures between Celsius, Fahrenheit, and Kelvin. It provides accurate conversion results with input validation and a simple, user-friendly interface.

## ✨ Features

- **Temperature Input:** Enter a temperature value.
- **Multiple Units:** Select Celsius, Fahrenheit, or Kelvin as the input unit.
- **Instant Conversion:** Convert the entered temperature into all three units.
- **Input Validation:** Displays an error message for invalid or empty inputs.
- **Absolute Zero Validation:** Prevents temperatures below absolute zero.
- **Formatted Results:** Displays conversion results up to two decimal places.
- **Responsive Design:** Works on different screen sizes.

## 🛠️ Technologies Used

- HTML5 – Structure of the application.
- CSS3 – Styling and responsive layout.
- JavaScript – Temperature conversion and validation logic.
- Remix Icon – Icon library integration.

## 🌡️ Temperature Conversion Formulas

| Conversion | Formula |
|---|---|
| Celsius to Fahrenheit | (°C × 9/5) + 32 |
| Celsius to Kelvin | °C + 273.15 |
| Fahrenheit to Celsius | (°F − 32) × 5/9 |
| Fahrenheit to Kelvin | (°F − 32) × 5/9 + 273.15 |
| Kelvin to Celsius | K − 273.15 |
| Kelvin to Fahrenheit | (K − 273.15) × 9/5 + 32 |

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your web browser.
4. Enter a temperature value.
5. Select the input unit.
6. Click the **Convert** button to view the results.
